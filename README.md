Expense Tracker 💸

Пет-проект на Python — консольный трекер расходов. Позволяет добавлять траты по категориям, смотреть всё сразу, считать общую сумму и фильтровать по категории.
Возможности

· ➕ Добавление расхода с указанием категории и суммы
· 📋 Просмотр всех расходов
· 💰 Подсчёт общей суммы потраченного
· 🔍 Фильтрация расходов по категории
· 🚪 Выход из программы
Структура кода

Функция Назначение
add_exp() Запрашивает категорию и сумму, добавляет запись в список exp
sh_all() Выводит все расходы с нумерацией
show_total() Считает и печатает сумму всех расходов
show_by_category() Фильтрует расходы по введённой категории
main() Главный цикл с меню

Данные хранятся в списке exp в виде словарей:
{"category": "еда", "amount": 350.0}
